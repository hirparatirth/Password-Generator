# 🔐 Python Password Generator

- 🔑 Generate random passwords.
- 📏 Customize password length.
- 🔠 Include uppercase and lowercase letters.
- 🔢 Include numbers.
- 🔣 Include special characters.
- 💻 Simple terminal-based interface.

## 🧠 Concepts Used

This project uses Python modules, functions, variables, data types, user input and output, conditional statements, loops, string manipulation, secure random selection using `secrets.choice()`, exception handling, input validation, and built-in functions.
